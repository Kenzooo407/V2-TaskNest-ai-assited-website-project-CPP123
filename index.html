Privacy Policy

How TaskNest handles information.

♧

Last updated: October 24, 2026

TaskNest is a student task organizer project created for the CPP123 Emerging Technology course. This policy describes how the current version of the website handles information.

1. Information stored

Tasks you enter, including task titles, subjects, due dates, priority levels, notes, and completion status, are saved in your browser's local storage on the device and browser you use. The current version does not send these task details to a server.

2. How information is used

The information is used only to display your task list, calculate progress, and organize deadlines within the website. The login screen is a demonstration-only gate: any non-empty username and password are accepted, and no real account is created or verified. A temporary signed-in flag is kept in the browser session. TaskNest does not have a real authentication server and does not sync tasks across devices.

3. Sharing and third-party services

The current version does not intentionally share task information with other users or third parties. If the site is later connected to hosting analytics, cloud storage, or other services, this policy must be updated to accurately describe those services.

4. Storage and deletion

Task information remains in your browser's local storage until you delete individual tasks or clear the website's browser data. If you use a shared device, other people who can access the same browser profile may be able to see your tasks. Do not enter passwords, sensitive personal information, or confidential records.

5. Security and limitations

Local browser storage is convenient but is not a secure backup. Data may be lost if browser data is cleared or the device is changed. Use fictional or non-sensitive information for classroom demonstrations.

6. Children's privacy

This educational project is intended as a general student productivity tool and is not designed to collect sensitive information from children.

7. Contact

For questions about this student project or its privacy practices, contact the student developer through the contact method provided by the course instructor. A direct public contact address is not currently provided on this prototype.
